1. ENV SECURITY FIX - Removed NEXT_PUBLIC_ prefix from secret keys
------------------------------------------------------------------
Problem: NEXT_PUBLIC_ prefix exposes values to the browser. Secret keys
must never be browser-exposable.

- .env.local: NEXT_PUBLIC_KHALTI_SECRET_KEY  ->  KHALTI_SECRET_KEY
- .env.local: NEXT_PUBLIC_ESEWA_SECRET_KEY   ->  ESEWA_SECRET_KEY
- src/app/api/payments/khalti/route.ts          (updated to process.env.KHALTI_SECRET_KEY)
- src/app/api/payments/khalti/initiate/route.ts (updated to process.env.KHALTI_SECRET_KEY)
- src/app/api/payments/khalti/verify/route.ts   (updated to process.env.KHALTI_SECRET_KEY)

Note: NEXT_PUBLIC_KHALTI_PUBLIC_KEY should ALSO be renamed by hand to
KHALTI_PUBLIC_KEY in .env.local - it is not used anywhere in the code,
so no code change is needed. After that NO NEXT_PUBLIC_ vars remain.
